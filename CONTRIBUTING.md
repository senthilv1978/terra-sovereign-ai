# Contributing

Thanks for helping make sovereign AI more practical and accountable.

## Good first contributions

- Add a policy profile showing residency, purpose, access, and export controls.
- Improve keyboard access, contrast, small-screen layouts, or screen-reader labels.
- Add a synthetic scenario and explain its assumptions.
- Review the threat model: identify what an update, aggregate, or model output could reveal.
- Adapt the concept to another public-interest use case while keeping local governance central.

## Guardrails

- Never commit personal, confidential, or real farm data.
- Label simulated values and avoid presenting the demo as a validated forecast.
- Explain who benefits, who bears risk, and how people can challenge an output.
- Keep external dependencies optional and document them.

## Submitting a change

Describe the user problem, the countries or stakeholders affected, the data movement involved, and how you checked the result. For UI changes, include a screenshot when possible.
